# Эйлер — промостраница

Вёрстка фрейма [3303:39 из Figma](https://www.figma.com/design/v5LtS1JVmKmytVHVtQphks/oskar?node-id=3303-39).

React, TypeScript, Vite, обычный CSS, GSAP ScrollTrigger и Lenis. Все изображения и SVG из макета лежат в `public/assets`, установленный TT Neoris Variable — в `public/fonts`.

## Запуск на другой машине

Нужны Git и Node.js с npm. Текущая версия проверена на Node.js **24.12.0**, версия также указана в `.node-version`. Репозиторий приватный: для клонирования нужен доступ к аккаунту `zhenchur` через GitHub CLI, Git Credential Manager или SSH.

```sh
git clone https://github.com/zhenchur/euler-promo.git
cd euler-promo
npm ci
npm run dev
```

Страница открывается по адресу [http://127.0.0.1:4190/](http://127.0.0.1:4190/). Порт 4190 должен быть свободен. Ключи API, `.env` и серверная часть для запуска не нужны. Все необходимые локальные ассеты включены в репозиторий.

```powershell
npm run build
npm run preview
```

Перед `npm run preview` остановите dev-сервер: обе команды используют порт 4190. Сборка находится в `dist`; зависимости устанавливаются из `package-lock.json`. Папки `node_modules`, `dist` и локальные записи проверок `qa` в Git не включены.

Для получения следующих изменений:

```sh
git pull --ff-only
npm ci
npm run dev
```

## Где продолжать работу

| Файл | Назначение |
| --- | --- |
| `src/App.tsx` | Секции страницы, меню, видео, карточки и заглушка для небольших экранов |
| `src/styles.css` | Стили и масштабирование десктопного макета |
| `src/components/SiteIntro.tsx` | Прелоадер и анимация первого появления |
| `src/motion/usePromoScroll.ts` | Фиксация промо, белые окна, Lenis и переходы по якорям |
| `src/components/Metrics.tsx` и `Metrics.css` | Секция с показателями |
| `public/assets` и `public/fonts` | Изображения, SVG и шрифт |

Это одностраничник без роутера. Изменения анимации загрузки нужно проверять обновлением страницы на `/` или `/#top`.

## Макет и поведение

- При первом открытии временный прелоадер с логотипом заполняется, затем уходит вверх по диагонали. Промо выравнивается из `scale: 1.3`, поворота `7°` и вертикального смещения; после него появляются текст, бенефиты и меню. Последовательность адаптирована из холодного запуска [Exo Ape](https://www.exoape.com/), без переходов между страницами.
- Прелоадер ждёт декодирования обложки и готовности шрифта, ограничивает ожидание ресурсов 5,5 секунды и имеет аварийное завершение через 8 секунд. Прокрутка включается после очистки стартовых трансформаций. При `prefers-reduced-motion` и прямой ссылке на внутреннюю секцию стартовая анимация пропускается. Возврат по логотипу и изменение ширины после завершения не запускают её повторно.
- Исходная композиция рассчитана на 1920 px и пропорционально масштабируется до 1280 px. В более узких окнах и на сенсорных устройствах без мыши/трекпада показывается заглушка «Откройте проект на компьютере». Мобильной и планшетной вёрстки нет.
- Первый экран занимает высоту viewport за вычетом 32 px: снизу виден край белой секции. Тезисы стоят у нижнего края; для невысоких окон отступы и типографика становятся компактнее. В экстремально низких окнах высота растёт по содержимому, чтобы соседняя секция не закрывала текст.
- Промо, включая фон, заголовок и тезисы, зафиксировано при прокрутке. Меню всегда видно поверх страницы; на промо и первой белой секции его фон прозрачный. Начиная с «Андромеды», под меню фиксируется сплошная полоса в цвет фона зоны, которая закрывает проходящие карточки и текст. Полоса заканчивается точно на границе белых масок и не меняет высоту блоков. Когда первая белая секция достигает границы под меню, справа появляется «Получить аналитику»; при возврате к промо кнопка скрывается.
- Все `.white-panel` используют общую маску: верхний край останавливается ниже меню, нижний остаётся видимым с отступом, равным боковым полям. Содержимое прокручивается внутри этого окна вместе со страницей. Верхняя граница вычисляется как `header.top + header.bottom`, поэтому расстояния от меню до верха окна и до секции равны, включая CTA. При ширине 1920 px граница находится на 72 px. В конце секция схлопывается, сохраняя радиус. В стартовом состоянии нижняя дуга первой белой секции вынесена за экран и появляется только на последних 40% её подхода к меню. Ширина секций постоянна, раскрытия по горизонтали нет.
- Во время наезда первой белой секции промо плавно уменьшается до `scale: 0.94` и исчезает. Трансформация применяется к единому внутреннему слою `.hero__visual`, отдельно от меню и стартового появления страницы.
- Обёртка первой белой секции прозрачная: при её наезде и фиксации виден исходный фон промо без движущейся синей подложки. «Андромеда» прокручивается обычным образом под белыми панелями. Сплошной синий фон начинается только с «Андромеды» и заполняет оставшуюся высоту страницы, закрывая промо в конце.
- Плавный скролл Lenis синхронизирован со ScrollTrigger через один GSAP ticker. При `prefers-reduced-motion` используется обычная прокрутка с той же геометрией масок. При переходе к заглушке экземпляр Lenis, обработчики и ScrollTrigger очищаются.
- Высота исходного фрейма — 6871 px; пустая синяя область в конце сохранена на десктопе.
- Сохранены тексты, числа, шрифт, изображения и порядок блоков из указанного фрейма.
- «Возможности» и «Видеообзор» ведут к разделам страницы. «Тарифы», «Команда», «Контакты», «Получить аналитику» и «Подробнее» открывают соответствующие официальные страницы.
- Якоря учитывают текущую геометрию меню: верх раздела «Возможности» оказывается на границе маски, видео — на 16 px ниже неё. Логотип возвращает страницу к началу. Это работает и при открытии прямой ссылки с якорем.
- Видео запускается по клику и воспроизводит официальный ролик Эйлера. Для него необходим интернет.
- Карточки Андромеды переключаются стрелками и нажатием; доступно управление клавиатурой и состояния фокуса.
- При переходе к заглушке десктопная страница размонтируется, воспроизведение видео останавливается. На телефоне и планшете изображения и видео промостраницы не загружаются.
- Отправки заявок и серверной части нет: форма получения доступа открывается на сайте Эйлера.

## Проверка

`npm run build` проверяет TypeScript и собирает production-версию. Браузерная проверка охватывает десктопные размеры, заглушку, границу 1280 px, сенсорные устройства, изменение размера окна, навигацию, выбор карточек и видео. Исходная десктопная композиция сверена с экспортом указанного фрейма Figma.

Геометрия скролла дополнительно проверена на 1280, 1440, 1624, 1920 и 2560 px: фиксация промо/меню, симметричные отступы вокруг меню, исчезновение обеих белых панелей, сохранение радиусов, появление CTA, плавная прокрутка колёсиком и обратный переход к началу. `src/motion/usePromoScroll.ts` содержит общий контроллер прокрутки; новые белые секции подключаются классом `.white-panel`.
